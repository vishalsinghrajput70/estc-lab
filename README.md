# ESTC Lab — BS in Electronic Systems

Course pages for the first-semester ESTC laboratory.

## Contents

- `index.html` — **Experiment 1: your kit and RC filters.** Setup for the
  ADALM1000 (Pixelpulse2) and the BumbleBee ScopeX, the loop-back test, and
  the RC low-pass, high-pass and optional band-pass filters, with a live
  filter bench, schematics, breadboard wiring pictures and readings tables.

Each page is a single self-contained HTML file: diagrams are inline SVG and
all behaviour is inline JavaScript. The only external request is two Google
Fonts stylesheets.

## Publishing

Settings → Pages → Deploy from a branch → `main` / root. The site appears at
`https://<user>.github.io/estc-lab/`.

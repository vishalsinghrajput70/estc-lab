Your kit, and an RC low-pass filter

Install the software, prove the kit can generate and measure a signal, then build a filter with one resistor and one capacitor and watch the output shrink as the frequency rises. Works with the ADALM1000 or the BumbleBee ScopeX.

Pick your kit once, below — every instruction and every pin label on this page then matches the kit in front of you.

What you will do today

  • Install the software and get the kit recognised.
  • Generate a sine, square and triangle wave.
  • Feed the generator straight back into a measuring channel — the loop-back test.
  • Build an RC low-pass filter with a cut-off near 1 kHz and record how the output swing falls as frequency rises.

What you need on the bench

  • Your kit and its USB cable
  • Breadboard and jumper wires (header pins for the ADALM1000)
  • One resistor and one capacitor, chosen for a cut-off near 1 kHz — 1.6 kΩ with 0.1 µF gives 995 Hz
  • A laptop running Windows for the kit software
When the kit is plugged in correctly a light comes on: a red light on the ADALM1000, an LED on the ScopeX. No light means no power — try another USB port or cable before anything else.

Part A — install the software and connect the kit

ADALM1000 with Pixelpulse2

  1. Search for Pixelpulse2 and open its GitHub page.
  2. Open the Releases section and find the Windows installer. The .dmg files are for Mac; ignore those.
  3. Run the setup file and install it, then open Pixelpulse2. The window shows Channel A and Channel B.
  4. Plug the small end of the USB cable into the kit and the other end into your laptop. The red light on the kit should glow.
  5. Open Settings → Display Settings and raise the dot brightness so the waveform is easy to see.
Each ADALM1000 channel can do one of two jobs: source a signal, or measure one. Today Channel A generates and Channel B measures.

BumbleBee ScopeX with scopex.exe

  1. Go to the Bumblebee Instruments website, open Products, find ScopeX and click View Specifications. That links to the GitHub page with the downloads.
  2. Install the drivers first if you have never used an ATmega-based board on this laptop. If you have, skip this.
  3. Download the Windows application, extract the compressed folder, and run scopex.exe from inside it. There is no install wizard.
  4. Plug in the USB cable. An LED glows on the kit and the application should show Connected.
  5. Find these on the board before you start: the SIG pin, the two scope channel inputs, the GND pins, and the two potentiometers (one amplitude, one offset).
On the ScopeX the amplitude and offset are physical knobs, not software settings. The power pins (3.3 V, 5 V, ±12 V) and the digital pins are not needed today.

Part B — the loop-back test

Before trusting any measurement, prove the kit can generate and measure at the same time. Join the generator output straight to a measuring input with one wire: whatever you send must come back unchanged.

  1. Fit the header pins. There are eight positions per side but you need six: leave the end position empty on each side (those are A-in and B-in, unused here).
  2. In Pixelpulse2 click the arrow on Channel A and choose the sine wave. Set 1000 Hz and 2.5 V, then press Play.
  3. Run a wire from the Channel A output (white) to the Channel B input (grey). The same waveform should appear on Channel B immediately.
  4. Change the settings — try 100 Hz at 5 V. Channel B should show the same frequency and the same 0 to 5 V swing.
  5. Switch Channel A to a square wave, then a triangle. Each one comes straight back on Channel B.
Square and triangle waves can look smaller on Channel A than on Channel B. That is only because Channel A has half the screen height — check the Y axis and you will see both run 0 to 5 V.
  1. Run a jumper from the SIG pin to Channel 1 of the scope (Channel 2 works equally well).
  2. Open Signal Generator and click Run Signal Generator. Everything is off by default. A 1000 Hz sine now leaves the SIG pin.
  3. Go to the Scope section and click Run. A distorted-looking wave at this stage is normal.
  4. Raise the sampling rate until the wave is clean. Roughly ten times the signal frequency works — about 10 kHz for a 1 kHz sine.
  5. If the wave will not sit still, set the trigger source to Channel 1.
  6. Turn the two potentiometers slowly and watch the amplitude and the offset respond.
  7. Use the measurement panel to read frequency, peak-to-peak, mean, amplitude, period and maximum. Confirm the frequency reads about 1 kHz.

Once the generated wave comes back cleanly, the kit is proven and you can move to the filter.

Part C — build the RC low-pass filter

The same two components in series. Which one you measure across decides what the filter does: across the capacitor gives a low-pass, across the resistor gives a high-pass. From here the circuit is identical on both kits; only the pin names change.

How the breadboard is joined inside

In the main area, the five holes of each row group are joined together — columns a to e as one group, f to j as another — and the two halves are not joined across the centre channel. The long rails down each edge run the length of the board, and the top pair is separate from the bottom pair.

The wiring, hole by hole

Build the band-pass in two stages on the same board: wire the high-pass first (C1 then R1 to ground) and check it alone, then take its output into R2 and put C2 from that node to ground. Keep R2 about ten times R1, so the second stage barely loads the first.
  1. Place the resistor across two separate column strips, and connect one end of the capacitor to the far end of the resistor.
  2. Take the other end of the capacitor to the ground rail.
  3. Join the kit ground to that same rail. This shared ground is what makes the measurement meaningful.
  4. Feed the input to the free end of the resistor — Channel A on the ADALM1000, the SIG pin on the ScopeX.
  5. Connect the measuring channel to the point where the resistor meets the capacitor. That node is the filter output.
  6. Check every joint once more, then power up and set the generator to a 5 V sine.
The kit ground and the breadboard ground must be joined. Connecting only the input and the measuring channel is not enough — without the shared ground you will see a badly distorted voltage and may spend an hour chasing a fault that isn't there. This applies to both kits.

Take your readings

Drive the input with a 5 V sine and step the frequency, watching the output. On the ADALM1000 set the amplitude in software; on the ScopeX use the amplitude knob and check the swing on screen. The expected column assumes R = 1.6 kΩ and C = 0.1 µF.

What you should have found

The low-pass held full swing below its cut-off and shrank above it, lagging the input. The high-pass did the opposite with the very same resistor and capacitor: it cut the low frequencies and let the high ones through, leading the input instead of lagging. The band-pass simply puts one after the other, keeping a strip of frequencies and rejecting everything on either side. In all three the corner frequency comes from the same expression, 1 / (2πRC).

Optional extension — the band-pass filter

If you have finished the low-pass and the high-pass and have bench time left, try this. It is not required, and no marks depend on it.

The idea

A band-pass keeps a strip of frequencies and rejects both the low and the high end. The simplest passive version is a high-pass stage followed by a low-pass stage: the first removes everything below its corner, the second removes everything above its own. The two corners must be set apart, with the high-pass corner lower than the low-pass corner, or nothing gets through at all.

Suggested values

StageComponentsCorner frequencyJob
1 · high-passC1 = 0.1 µF in series, R1 = 1.6 kΩ to groundabout 1 kHzblocks everything below 1 kHz
2 · low-passR2 = 16 kΩ in series, C2 = 1 nF to groundabout 10 kHzremoves everything above 10 kHz
Why R2 is ten times R1: the second stage draws current from the first, which shifts both corners if the two stages have similar impedance. Keeping R2 well above R1 keeps that loading small, so each stage behaves roughly as its own formula predicts. Measure the corners rather than assuming them.

What to look for

  • Sweep from 100 Hz to 20 kHz and find where the output is largest. That is the middle of the band.
  • Find the two frequencies where the output has fallen to about 71 % of its peak. Those are your measured corners — compare them with 1 kHz and 10 kHz.
  • Check the phase: the output leads the input below the band and lags it above the band.
  • Try swapping the order of the two stages. The shape should be similar; explain in one line why the loading changes.

Troubleshooting

What you seeLikely cause and fix
Output looks distorted or wanders aboutKit ground and breadboard ground are not joined. This is the single most common fault in this experiment.
Kit not detected by the softwareADALM1000: check the red light and try another USB port. ScopeX: install the ATmega drivers, then reopen scopex.exe.
Wave will not sit still on screenSet the trigger source to the channel you are measuring.
Sine looks jagged or triangularSampling rate too low. Aim for about ten times the signal frequency.
Output equals the input at every frequencyThe capacitor is not really in circuit, or you are probing the input node instead of the R–C junction.
Output is tiny even at 100 HzR and C are the wrong values, or a leg is in the wrong strip. Check the joints across the centre channel.
Nothing at all on the measuring channelGenerator not started. On the ScopeX the generator is off until you click Run Signal Generator.

Before you leave the bench

  • Loop-back test done on sine, square and triangle.
  • Filter built, with the capacitor's far end and the kit ground on the same rail.
  • All four frequency readings recorded in the table.
  • You can explain in one sentence why the output shrinks above the cut-off.
